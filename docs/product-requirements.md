# Orbit 产品需求文档

## 产品概览

Orbit 是一个“主动发现 + 个性化编排 + 可审批执行”的个人休闲 Agent。它不替用户刷遍赛事、电影与活动资讯，而是发现少量高质量机会，结合用户本次诉求、长期偏好、时间与预算生成可执行方案；任何日历、提醒等外部写操作都必须经用户确认。

核心闭环：

```text
主动机会 → 机会详情/聊天协商 → 本次条件确认 → 方案比较
→ 审批 → 执行结果 → 反馈学习 → 下一次更贴近的推荐
```

产品原则：主动但不过度打扰；长期偏好只作建议；本次条件必须可见、可编辑、可删除；AI 不可绕过审批。

## M1 首次引导与授权

目标：低摩擦开始使用，并明确授权价值。

- 用户可选择兴趣域，跳过详细偏好。
- 日历、通知、位置均延后到需要时解释并授权。
- 授权页显示状态、用途、撤销入口。

验收：未授权日历仍能生成方案；用户能在偏好页查看和修改各授权状态。

## M2 首页与主动机会

目标：让用户一打开就看到值得处理的事，而不是空白聊天框。

- 首页按顺序展示：需要你处理、本周安排、每日一条高质量邀约、发现的新机会。
- 机会卡显示来源、更新时间、时间/预算摘要及推荐理由。
- 每张机会卡支持：围绕它聊聊、不感兴趣、少推荐此类。
- 每日邀约最多一条；无高质量机会时显示空状态，不凑数。

验收：点击机会能带上下文进入聊天；负反馈立即隐藏卡片并影响后续排序。

## M3 聊天协商与本次条件

目标：将模糊想法转为本次可执行约束。

- 聊天从空条件开始；只提取用户本次明确表达或明确采纳的条件。
- 顶部展示本次条件，包含来源、编辑、单项删除与清空全部。
- 长期偏好仅以“Orbit 的建议”展示，用户点击后才加入本次条件。
- Agent 只追问时间、预算、同行、方式等会影响方案可行性的缺失信息。
- 提供低成本快捷选择，如在家看、去酒吧、都准备。

验收：同一用户的两次新聊天不会自动带入固定预算/时间条件；用户可清空后重新协商。

## M4 用户画像与长期偏好

目标：让 Orbit 越来越懂用户，但不产生黑箱画像。

- 长期偏好包括兴趣、预算、通勤、惊喜频率与避开项。
- 画像推断必须展示证据，例如“近期 4 次选择低通勤”。
- 用户可编辑偏好、删除单项推断、保存或忽略画像建议。
- 本次条件不能静默升级为长期偏好。

验收：删除推断后后续排序不再使用该信号；偏好变更只影响新任务。

## M5 方案比较与详情

目标：用户能理解 Plan A/B/C 的取舍并做出选择。

- 每个方案显示时间、地点/线上、通勤、预算、推荐理由、来源、数据时效与待执行动作。
- Plan A/B/C 分别体现最匹配、更轻松、新体验等明确差异。
- 支持收藏方案、换个方向重新生成。
- 数据过期、时间冲突或超预算时，不可进入审批。

验收：用户在一屏可判断三个方案的核心差异；无可行方案时展示冲突原因与调整入口。

## M6 审批与执行结果

目标：每个外部副作用都可见、可编辑、可追溯。

- 审批页列出日历、提醒等动作及写入位置。
- 支持编辑标题、时间、提醒；可关闭非必要动作。
- 支持批准、拒绝（附原因）、稍后处理。
- 结果页区分成功、部分成功、失败重试；支持打开模拟日历事件。

验收：未批准前不创建动作；重复批准不重复执行；拒绝与编辑均写入任务记录。

## M7 任务中心与恢复

目标：让 Agent 任务可观察、可恢复，而不是一次性聊天。

- 任务按需要你处理、进行中、已完成分组。
- 不同状态展示不同详情：下一步、执行结果或运行进度。
- 详情包含本次条件、方案、审批、执行结果和可展开时间线。
- 失败可重试，网络/应用中断后仍能恢复任务。

验收：用户能从通知或任务中心恢复待审批任务；完成任务显示实际执行结果。

## M8 结果反馈与持续学习

目标：用低成本反馈增强下一次推荐，而非要求用户填写问卷。

- 执行结果后询问“这次安排怎么样？”。
- 提供很满意、下次少通勤、不喜欢这种安排等快捷反馈。
- 反馈先作为排序信号；只有足够证据时才提出保存为长期偏好的建议。

验收：反馈后页面显示已记录；下一次推荐理由能说明使用了何种偏好信号。

## MVP 边界

- 首版使用模拟赛事、电影、日历和通知数据。
- 不包含真实购票、订位、支付、抖音发布或金融交易。
- Android/KMP 优先；后端负责状态、审批、幂等和审计，AI 仅生成结构化建议。

## 模块交互输入/输出明细

| 模块 | 用户输入/触发 | 系统输出 | 用户后续交互 |
| --- | --- | --- | --- |
| M1 引导 | 选择兴趣、跳过、授权/暂不授权 | 初始偏好草稿、授权状态、首页机会 | 修改兴趣、稍后授权 |
| M2 首页 | 点击待审批、每日邀约、机会卡、负反馈 | 对应任务、机会详情或带上下文聊天 | 围绕它聊聊、不感兴趣、少推荐此类 |
| M3 聊天 | 文本、快捷选择、采纳建议、删除/清空条件 | 提取出的本次条件、追问、可生成状态 | 编辑条件、回答追问、生成方案 |
| M4 画像 | 编辑偏好、保存建议、删除推断、管理授权 | 更新后的偏好/证据/授权状态 | 撤销、再次编辑、忽略建议 |
| M5 方案 | 选择 Plan、收藏、换方向生成 | 时间/预算/通勤/来源/风险、候选方案 | 进入审批、收藏、生成新任务 |
| M6 审批 | 编辑标题/时间、开关动作、批准/拒绝/稍后 | 校验结果、执行中状态、成功/部分失败/拒绝记录 | 重试失败动作、打开日历、查看任务 |
| M7 任务 | 打开待处理/进行中/已完成任务、重试、取消 | 当前下一步、时间线、执行结果 | 审批、恢复、重试、查看详情 |
| M8 反馈 | 很满意、少通勤、不喜欢、跳过 | 已记录反馈、未来排序信号、可选画像建议 | 保存为长期偏好、仅本次、删除推断 |

### 条件字段规则

| 用户输入 | 生成的本次条件 | 输出/追问 |
| --- | --- | --- |
| “周末” | `时间=本周末（来自本次表达）` | 若范围不足，询问具体日期 |
| “预算 300” | `预算=¥300（来自本次表达）` | 校验金额，超过/低于可行范围时提示 |
| “看利物浦” | `兴趣=利物浦比赛（来自本次表达）` | 查询赛程；无比赛则提供替代方案 |
| 点击“常用预算 ¥300” | `预算=¥300（已采纳建议）` | 可编辑/删除，不改长期偏好 |
| 点击机会卡 | `机会上下文=机会 ID` | 显示来源、时效，并追问方式/同行人 |
| 删除条件 | 从本次条件移除 | 重新判断是否仍满足生成门槛 |

### 审批输入/输出规则

- 输入：计划 ID、动作开关、编辑后的标题/时间/提醒、批准/拒绝/稍后决定。
- 输出：字段校验错误，或 `EXECUTING`、`COMPLETED`、`COMPLETED_WITH_WARNINGS`、`REJECTED`。
- 批准必须返回动作级结果：日历事件引用、提醒状态、失败原因、是否可重试。
